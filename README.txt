* category.csv - файл где хранятся категории разделения «отдаления» специалиста от пользователя. Обращаются к нему с файла predict.py
* get_parsing.py - в данном файле размещается функция для парсинга данных специалиста или школьника. Функцию в данном файле вызывают из файла users.py и specialist.py. В данной функции вызывается файл login.py
* login.py - необходим для получения токена 
* predict.py - загрузка на сервер данных с использованием API, сейчас ведется работа с этим файлом. Он имеет тестовый вариант функционала
* specialist.py - создание кластеров специалистов, от 2 до количества уникальных профессий. В процессе работы сохраняет текущую дату и время запуска, записывает эти данные в папку data. В эту же папку записывает данные о сохраненных переменных необходимых для работы файла users.py. В очередной версии были добавлены получения результатов метрик SS, DBI, CHI
* users.py – служит для создания json файлов учеников в которых записана информация о их кластеризации. Запись осуществляется в папку data_user, каждый пользователь записан под именем user_id_X, где X – id пользователя. В очередной версии были добавлены сохранения результатов метрик SS, DBI, CHI
* users_tabl.py – временный файл (скорее всего) для нахождения количество встречаемости уникальной профессии, среднего арифметического, медианы, стандартного отклонения и среднего геометрического
* visualization.py - визуализация данных, есть с чем работать …
